# WhisperNet

WhisperNet is our **final-year academic project** developed as a group.

It is a web-based application that combines a user-friendly frontend with backend services to provide its core functionality.

## Features

- Clean and responsive user interface
- Multiple pages and modules
- Interactive dashboard and components
- Education module
- Backend API integration
- Data visualization
- Map-based features

## Technologies Used

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- Node.js
- Express.js
- Python
- Flask
- MATLAB

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/AkshayTomer/Whisper-net.git
cd Whisper-net
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install --legacy-peer-deps
```

### 3. Install backend dependencies

```bash
cd ../backend
npm install
```

### 4. Start the project

From the main project folder:

```bash
npm run dev
```

The frontend will normally be available at:

```text
http://localhost:3000
```

> **Note:** Some features require the Python/MATLAB service to be installed and configured separately.
